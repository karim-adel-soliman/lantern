# Lantern

A tiny command-line task tracker written in Python 3 (standard library only).

## Install and usage

```bash
git clone https://github.com/karim-adel-soliman/lantern.git
cd lantern
python3 lantern.py add "Buy milk"
python3 lantern.py list
```

## Commands

- `add <title>`: add a task
- `list`: list all tasks
- `list --done`: show only completed tasks
- `list --sort`: show tasks sorted by title
- `export --csv`: print tasks as CSV

See [docs/usage.md](docs/usage.md) for more details.
